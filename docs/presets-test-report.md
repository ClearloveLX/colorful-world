# Preset 测试报告

## 覆盖范围

- 数据层：创建、更新、删除、重排、重名冲突、非法标签
- 并发：并发创建、并发重排后 `sort_order` 无重复且无跳号
- 桌面端冒烟：图片页与视频页均支持保存预制、选择预制、管理预制

## 执行命令

```powershell
python -m unittest discover -s tests -p "test_presets.py" -v
```

## 预期闭环

1. 勾选标签
2. 点击“保存为预制”
3. 切换成另一组标签
4. 选择刚保存的预制
5. 标签被覆盖并恢复为保存时状态

## 本次结果

- 自动化：`7` 项测试全部通过，耗时约 `0.971s`
- 自动化覆盖：创建、更新、删除、重排、重名冲突、非法标签、并发创建、并发重排
- 手工冒烟：待按图片/视频页面各执行一轮闭环后回填

## 关注点

- 软删除后仅重排未删除记录
- 图片与视频预制名称可同名，但互不影响
- 事务通过 `BEGIN IMMEDIATE` 保证并发创建和重排时序列连续
